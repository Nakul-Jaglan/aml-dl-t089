Context & Methods¶

The question is whether an explicit local-edge description changes classification compared with raw intensities, and whether that effect depends on the classifier.

  1. Official training data -> fixed stratified 48,000/12,000 fit/validation split, seed 42.
  2. Development: two candidates per row on a saved 12,000-image subset of the fit pool; unchanged validation set. This is a modest search, not exhaustive optimization.
  3. Final fitting: the eight development-selected configurations are fitted afresh on all 48,000 fit images, including each learned scaler. Validation labels are never fitted.
  4. Choose the overall final model using final validation macro F1 (then declared tie-breaks).
  5. Freeze artifact hashes, then evaluate all eight on the official 10,000-image test partition.

Key Assumptions¶

  • The one fixed split is representative enough for this course comparison; no repeated-seed or cross-validation uncertainty analysis is claimed.
  • Pixels and HOG are fixed transforms; learned standardization stays inside Pipelines.
  • Preprocessing is intentionally model-specific. Representation comparisons are comparisons of the declared pipelines, not a pure HOG ablation under every possible scaler.
  • Test error panels describe frozen models and do not authorize further test-driven tuning.
  • Full details and primary sources: docs/protocol.md, docs/literature_review.md, report/references.bib. Original dataset: https://github.com/zalandoresearch/fashion-mnist.

4. Inspect the two representations¶

Flattening preserves intensity values and their recoverable ordering but supplies no built-in local-neighborhood bias. HOG summarizes local gradients using a fixed rule. For this setup: 7 cells per axis -> 6 overlapping blocks per axis -> 6 x 6 x 2 x 2 x 9 = 1,296 values. HOG is not dimensionality reduction here.

5. Connect theory to the model factories¶

Model Decision rule Development setting Scaling
Logistic Regression Learned linear class scores; softmax classification C=0.1 or 1 StandardScaler
kNN Distance-weighted vote among stored neighbors k=3 or 5 Pixel passthrough; HOG standardized
Random Forest Combine randomized tree predictions depth=20 or unrestricted; 200 trees Passthrough
RBF SVM Nonlinear margin-based decisions C=1 or 10; gamma='scale' StandardScaler

Smaller LR C means stronger regularization. kNN can fit quickly while retaining expensive prediction/storage costs. RF samples training examples/features. SVC trains pairwise classifiers for the ten classes. See the actual code in src/clothing_ml/models.py.

7. Independently regenerate test metrics from predictions¶

Accuracy is total correct / N. Per-class recall is TP/(TP+FN). Macro F1 averages ten separately calculated class F1 values equally; it is not F1 of averaged precision/recall. Missing/duplicate sample IDs or incorrect true labels cause validation to fail.

12. Read fit time, inference time and complexity honestly¶

The benchmark starts with loaded models and in-memory data. End-to-end includes normalization, fixed feature extraction, scaler and classification; Pipeline-only begins at cached fixed features. Both exclude disk/model-loading time. Five repeats of 1,024 fixed test images in batches of 128 produce an amortized batch cost, not single-request latency.

Counts below describe different structures. kNN stored scalars, RF nodes and SVM support-vector storage are not interchangeable with neural-network-style trainable weights.
